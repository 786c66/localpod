# LocalPod

iOS 本地音频播放器：把「文件夹」当作播客订阅来管理和播放。

## 为什么做 LocalPod

本地音频文件常常散落在「文件」App、iCloud 云盘和外接目录里：系统音乐 App 不擅长管理播客，主流播客 App 又基本只能导入单个文件。LocalPod 直接吃整个文件夹——选一次，之后就像订阅了一档播客，自动发现新内容并保留原有目录结构。

## 特性

**导入**

- 文件夹递归导入：保留子目录结构，导入后按文件夹自动生成合集。
- 四种导入方式：文件 App 选择文件夹、AirDrop 与「用 LocalPod 打开」、Finder 收件箱（`Documents/Import`）、Wi-Fi 局域网网页上传（PIN 校验 + 二维码）。
- SHA-256 去重；导入可断点恢复，失败项可重试，不支持的文件单独隔离、不打断整批任务。
- 直接原地读取文件，不复制副本：通过安全作用域书签持续访问原文件夹；文件被移动或删除会标记为缺失，恢复后可重新关联。

**播放**

- 后台播放，锁屏与控制中心控制，支持 AirPlay。
- 倍速 0.5–3.0×，快进/快退，播放进度记忆。
- 队列管理：下一首播放、加入队列、自动下一集开关。
- 单曲循环、列表循环、随机播放。

**整理与扩展**

- 智能播放列表：继续播放、未播完、最近添加、已播完，并可按合集筛选。
- 自建播放列表，支持拖拽排序与播放全部。
- 睡眠定时（1–90 分钟或本集结束，到点前音量淡出）。
- 回收站保留 30 天，可随时恢复或清空。
- 章节识别：有声书/播客按章节跳转。
- 快捷指令与 Siri：继续播放、打开合集。
- 备份导出与合并恢复。
- 简体中文 / English 双语界面。

## 支持的文件类型与已知边界

- 支持 AVFoundation 能解码的音频格式；视频文件可以导入，但只播放音轨、不显示画面。
- 不支持 MKV / AVI / OGG 等 AVFoundation 无法解码的容器。
- 无 Share Extension（免费签名账号没有 App Groups 权限）。
- 无 CarPlay。
- Wi-Fi 上传需要手机与电脑处于同一局域网，且 App 保持在前台；进入后台即停止服务。

## 构建与安装

工程由 XcodeGen 从 `project.yml` 生成：

```bash
brew install xcodegen
xcodegen generate
open LocalPod.xcodeproj
```

- 选择任意 iPhone 模拟器即可直接运行，无需签名。
- 真机安装：在 Xcode 中登录免费 Apple ID，并在 Signing & Capabilities 里选择你的 Personal Team。免费签名 7 天有效，到期后需要重新签名安装。

## 技术栈

SwiftUI + SwiftData + AVFoundation，Swift 6，iOS 17+；核心逻辑抽成 `LocalPodKit` 以便独立测试。
