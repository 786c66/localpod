## 如何记录

1. **每完成一项**：在本文件勾选，并在「结果记录表」加一行；截图存 `docs/screenshots/`（建议命名 `DEVICE-<区块>-<项>.png`）。
2. **写回来源报告**：结果同时回填对应报告的原章节，例如 Wi-Fi 各项 → `docs/P1-REPORT.md` §6，锁屏/中断项 → `docs/M2-REPORT.md` §6，重签/备份项 → `docs/M5-INSTALL-RESIGN-BACKUP.md` §7 证据表，链接文件夹 → `PLAN.md` §5.10。各报告 §6 的「待真机验证（未计为通过）」标题在全部通过前不要改。
3. **口径**：任何项在真机确认之前不得写成「已通过」；标注「已有模拟器自动化覆盖，真机复核」的项通过后，可在对应报告把口径从「部分自动化」更新为「真机复核通过」。
4. **失败项**：保持不勾选，记录复现步骤、Xcode console 日志或诊断页信息与截图；不要为了通过而修改验收语义。
5. **不要改 PLAN.md 的勾选状态**：PLAN 的阶段勾选由各报告口径汇总，先更新报告再同步。
