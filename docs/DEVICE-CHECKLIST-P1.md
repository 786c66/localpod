## 10. 通知（P2）

> 模拟器自动化覆盖：`ImportNotificationPolicyTests`（11 个决策用例）与 `P2NotificationUITests`（真实收件箱导入 + 决策 seam + 开关持久化）。权限弹窗、后台实际送达、前台抑制、拒绝权限回退只能在真机验证。注意：App 仅声明 audio 后台模式，长导入在系统挂起后会暂停；只有 run 真正结束时才发通知（后台完成才可能送达；回前台完成会被前台抑制）。

- [ ] **首次开启权限弹窗**：设置 → 通知 → 打开「导入完成提醒」。预期出现系统通知权限弹窗（**启动 App 时不应出现任何权限弹窗**）；选择「允许」。失败看：iOS 设置 → 通知 → LocalPod 是否存在。（来源：PLAN.md §5.15）
- [ ] **后台导入送达（成功）**：导入一个较小文件夹后立刻切到后台/锁屏，等待导入完成。预期收到「导入完成」本地通知，正文含合集名与条目数；点击通知回到 App。失败看：通知权限、专注模式/通知摘要、导入是否被系统挂起。（来源：PLAN.md §5.15）
- [ ] **前台抑制**：App 在前台完成导入。预期不出现通知横幅，导入页/收件箱页显示结果摘要；同一 run 不重复打扰。（来源：PLAN.md §5.15）
- [ ] **失败通知**：制造一次硬失败（如导入中移除源文件、磁盘写满）或让全部文件失败。预期收到「导入失败」通知并带错误信息；前台失败同样被抑制，错误显示在导入页。失败看：导入报告与错误详情。（来源：PLAN.md §5.15）
- [ ] **取消与空跑不通知**：导入中点击「取消导入」；再导入一次内容全部重复的同一文件夹。预期两者都不发通知。（来源：PLAN.md §5.15）
- [ ] **拒绝权限回退**：首次开启时选择「不允许」。预期开关自动回到关闭，并显示「去 iOS 设置允许通知」的提示；到 iOS 设置 → 通知 → LocalPod 允许后，回到 App 重新开启，开关保持开启。失败看：设置页拒绝提示行。（来源：PLAN.md §5.15）
- [ ] **关闭开关即停**：关闭「导入完成提醒」后完成一次后台导入。预期无通知；重启 App 后开关仍为关闭。（来源：PLAN.md §5.15）
