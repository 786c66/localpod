# M0 真机清单（待你执行）

> 用途：M0 模拟器无法覆盖的真机项。执行后把结果补到本文件；不影响 M1 开发。

## 1. 免费账号签名 / 7 天过期

- [ ] Xcode 登录免费 Apple ID，Personal Team 签名安装主 App。
- [ ] 诊断页记录描述文件到期时间、剩余天数。
- [ ] 到期后确认 App 无法启动。
- [ ] 同一 Bundle ID 覆盖重签，确认资料库条目、导入文件、播放进度仍存在。
- 记录：首次安装日期 ____；到期 ____；重签后条目数 ____。

## 2. 锁屏与控制中心

- [ ] 播放音频后锁屏，确认继续播放。
- [ ] 锁屏显示标题、封面、进度，可播放/暂停。
- [ ] 控制中心可播放/暂停、±15 秒、拖动进度。
- [ ] 来电/闹钟中断后可恢复；拔耳机暂停。

## 3. 真机视频

- [ ] H.264 文件有画面、可全屏、可旋转。
- [ ] HEVC 文件有画面、可全屏。
- [ ] 视频退到后台默认暂停；回前台恢复。
- [ ] （可选）AirPlay 到电视有画面。

## 4. 最老支持机型 / 100 文件

- [ ] 在 iOS 17 最老支持 iPhone 上，从文件 App 选择 3 层、100 个媒体文件的真实文件夹。
- [ ] 进度、取消、完成报告正常。
- [ ] 记录导入耗时、峰值内存；资料库 5000 条列表滚动是否明显卡顿。

## 5. 真实渠道

- [ ] Files 长按文件 → 共享 → LocalPod，导入 1 个。
- [ ] Finder 文件共享拖 1 个文件进 `Documents/Import`，回 App 自动导入。
- [ ] iCloud Drive 选一个含未下载文件的文件夹，确认下载进度、断网错误、联网重试。
